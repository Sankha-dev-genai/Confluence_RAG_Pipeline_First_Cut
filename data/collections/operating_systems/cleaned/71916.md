Computer [operating systems](/wiki/Operating_system "Operating system") can be categorized by technology, ownership, licensing, working state, usage, and by many other characteristics. In practice, many of these groupings may overlap. Criteria for inclusion is notability, as shown either through an existing Wikipedia article or citation to a reliable source.

### [Google](/wiki/Google "Google")

[![Image](//upload.wikimedia.org/wikipedia/commons/thumb/d/d5/Foldable_smartphone_%28Android_OS%29.jpg/250px-Foldable_smartphone_%28Android_OS%29.jpg?utm_source=en.wikipedia.org&utm_campaign=parser&utm_content=thumbnail)](/wiki/File:Foldable_smartphone_(Android_OS).jpg)

[Android OS](/wiki/Android_(operating_system) "Android (operating system)") on the [Samsung Galaxy Z](/wiki/Samsung_Galaxy_Z_series "Samsung Galaxy Z series") smartphones

- [ChromiumOS](/wiki/ChromiumOS "ChromiumOS") is an open source operating system development version of ChromeOS. Both operating systems are based on the [Linux](/wiki/Linux "Linux") kernel.
  - [ChromeOS](/wiki/ChromeOS "ChromeOS") is designed to work exclusively with web applications, though has been updated to run Android apps with full support for Google Play Store. Announced on July 7, 2009, ChromeOS is currently publicly available and was released summer 2011. The ChromeOS source code was released on November 19, 2009, under the BSD license as ChromiumOS.
  - [Container-Optimized OS](/w/index.php?title=Container-Optimized_OS&action=edit&redlink=1 "Container-Optimized OS (page does not exist)") (COS) is an operating system that is optimized for running Docker containers, based on [ChromiumOS](/wiki/ChromiumOS "ChromiumOS").[[13]](#cite_note-13)
- [Android](/wiki/Android_(operating_system) "Android (operating system)") is an operating system for mobile devices. It consists of [Android Runtime](/wiki/Android_Runtime "Android Runtime") (userland) with Linux (kernel), with its Linux kernel modified to add drivers for mobile device hardware and to remove unused Vanilla Linux drivers.
  - [Android TV](/wiki/Android_TV "Android TV")
- [gLinux](/wiki/GLinux "GLinux"), a Linux distribution that Google uses internally
- [Fuchsia](/wiki/Fuchsia_(operating_system) "Fuchsia (operating system)") is a [capability-based](/wiki/Capability-based_operating_system "Capability-based operating system") [real-time](/wiki/Real-time_operating_system "Real-time operating system") operating system (RTOS) [scalable](/wiki/Scalability "Scalability") to universal devices, in early development, from the tiniest [embedded](/wiki/Embedded_system "Embedded system") hardware, [wristwatches](/wiki/Smartwatch "Smartwatch"), tablets to the largest personal computers. Unlike ChromeOS and Android, it is not based on the Linux kernel, but instead began on a new microkernel called "Zircon", derived from "Little Kernel".
- [Wear OS](/wiki/Wear_OS "Wear OS") a version of [Google](/wiki/Google "Google")'s [Android](/wiki/Android_(operating_system) "Android (operating system)") [operating system](/wiki/Operating_system "Operating system") designed for [smartwatches](/wiki/Smartwatch "Smartwatch") and other [wearables](/wiki/Wearable_computer "Wearable computer").

#### On S/360, S/370, and successor mainframes

- [OS/360 and successors](/wiki/OS/360_and_successors "OS/360 and successors") on IBM S/360, S/370, and successor mainframes
  - [OS/360](/wiki/OS/360 "OS/360") (first official OS targeted for the [System/360](/wiki/System/360 "System/360") architecture)
    - PCP (Primary Control Program, a kernel and a ground breaking automatic space allocating file system)
    - [MFT](/wiki/MFT_(operating_system) "MFT (operating system)") (original Multi-programming with a Fixed number of Tasks, replaced by MFT II)
    - [MFT II](/wiki/MFT_(operating_system) "MFT (operating system)") (Multi-Programming with a Fixed number of Tasks, had up to 15 fixed size application partitions, plus partitions for system tasks, initially defined at boot time but redefinable by operator command)
    - [MVT](/wiki/Multiprogramming_with_a_Variable_number_of_Tasks "Multiprogramming with a Variable number of Tasks") (Multi-Programming with a Variable number of Tasks, had up to 15 application regions defined dynamically, plus additional regions for system tasks)
    - **M65MP** (MVT with support for a multiprocessor 360/65)
  - [OS/VS](/wiki/OS/VS "OS/VS") (port of OS/360 targeted for the [System/370](/wiki/System/370 "System/370") [virtual memory](/wiki/Virtual_memory "Virtual memory") architecture (OS/370 is not the correct name for OS/VS1 and OS/VS2.) OS/VS has the following variations:
    - [OS/VS1](/wiki/OS/VS1 "OS/VS1") (Operating System/Virtual Storage 1, Virtual-memory version of OS/360 MFT II)
      - **OS/VS1 Basic Programming Extensions** (BPE) adds device support and VM handshaking
    - OS/VS2 (Operating System/Virtual Storage 2, Virtual-memory version of OS/360 MVT)
      - OS/VS2 R1 (Called [Single Virtual Storage](/wiki/OS/VS2_(SVS) "OS/VS2 (SVS)") (SVS), Virtual-memory version of OS/360 MVT but without multiprocessing support)
      - OS/VS2 R2 through R3.8 (called [Multiple Virtual Storage](/wiki/Multiple_Virtual_Storage "Multiple Virtual Storage"), MVS, eliminated most need for VS1).
        - MVS/SE (MVS System Extensions)
  - MVS/SP (MVS System Product) V1
  - **MVS/370** refers to OS/VS2 MVS, MVS/SE and MVS/SP Version 1
  - [MVS/XA](/wiki/MVS/XA "MVS/XA") (MVS/SP V2, supports S/370 Extended Architecture, [31-bit](/wiki/31-bit_computing "31-bit computing") addressing)
  - [MVS/ESA](/wiki/MVS/ESA "MVS/ESA") (MVS supported Enterprise Systems Architecture, horizontal addressing extensions: data only address spaces called Dataspaces)
    - **MVS/SP V3**
    - **MVS/ESA SP V4** (a Unix environment was available for MVS/ESA SP V4R3)
    - **MVS/ESA SP V5** (the UNIX environment was bundled in this and all subsequent versions)
  - [OS/390](/wiki/OS/390 "OS/390") replacement for MVS/ESA SP V5 with some products bundled
  - [z/OS](/wiki/Z/OS "Z/OS") [z/Architecture](/wiki/Z/Architecture "Z/Architecture") replacement for OS/390 with [64-bit](/wiki/64-bit_computing "64-bit computing") virtual addressing
  - [Phoenix/MVS](/wiki/Phoenix_(computer) "Phoenix (computer)") (Developed at [Cambridge University](/wiki/Cambridge_University "Cambridge University"))
- [DOS/360 and successors](/wiki/DOS/360_and_successors "DOS/360 and successors") on IBM S/360, S/370, and successor mainframes
  - [BOS/360](/wiki/BOS/360 "BOS/360") (early interim version of DOS/360, briefly available at a few Alpha & Beta System/360 sites)
  - [TOS/360](/wiki/DOS/360_and_successors#TOS/360 "DOS/360 and successors") (similar to BOS above and more fleeting, able to boot and run from 2x00 series tape drives)
  - [DOS/360](/wiki/DOS/360_and_successors "DOS/360 and successors") (Disk Operating System (DOS), multi-programming system with up to 3 partitions, first commonly available OS for System/360)
    - DOS/360/RJE (DOS/360 with a control program extension that provided for the monitoring of remote job entry hardware (card reader & printer) connected by dedicated phone lines)
  - [DOS/VS](/wiki/DOS/VS "DOS/VS") (First DOS offered on System/370 systems, provided virtual storage)
  - [DOS/VSE](/wiki/DOS/VSE "DOS/VSE") (also known as VSE, upgrade of DOS/VS, up to 14 fixed size processing partitions )
    - **VSE/Advanced Functions** (VSE/AF) - Additional functionality for DOS/VSE
  - [VSE/SP](/wiki/VSE/SP "VSE/SP") (program product including DOS/VSE and VSE/AF)
  - VSE/ESA, replaces VSE/SP, supports ESA/370 and [ESA/390](/wiki/ESA/390 "ESA/390") with 31-bit addresses
  - [z/VSE](/wiki/Z/VSE "Z/VSE") (latest version of the four decades old DOS lineage, supports 64-bit addresses, multiprocessing, multiprogramming, SNA, TCP/IP, and some virtual machine features in support of Linux workloads)
- [CP/CMS](/wiki/CP/CMS "CP/CMS") (Control Program/Cambridge Monitor System) and successors on IBM S/360, S/370, and successor mainframes
  - [CP-40](/wiki/CP-40 "CP-40")/CMS (for System/360 Model 40)
  - [CP-67](/wiki/CP-67 "CP-67")/CMS (for System/360 Model 67)
  - [Virtual Machine Facility/370](/wiki/VM_(operating_system) "VM (operating system)") (VM/370) - the CP [virtual machine](/wiki/Virtual_machine "Virtual machine") [hypervisor](/wiki/Hypervisor "Hypervisor"), [Conversational Monitor System](/wiki/Conversational_Monitor_System "Conversational Monitor System") (CMS) operating system and supporting facilities for System/370 (24-bit addresses)
    - **VM/370 Basic System Extensions Program Product** (VM/BSE, AKA BSEPP) is an enhancement to VM/370
    - **VM/370 System Extensions Program Product** (VM/SE, AKA SEPP) is an enhancement to VM/370 that includes the facilities of VM/BSE
  - **Virtual Machine/System Product** (VM/SP) replaces VM/370, VM/BSE and VM/SE.
  - **Virtual Machine/Extended Architecture** (VM/XA) refers to three versions of VM that support System/370 Extended Architecture (S/370-XA) with 31-bit virtual addresses
    - **Virtual Machine/Extended architecture Migration Aid** (VM/XA MA) - Intended for MVS/370 to MVS/XA migration
    - **Virtual Machine/Extended Architecture Systems Facility** (VM/XA SF) - new release of VM/XA MA with additional functionality
    - **Virtual Machine/Extended Architecture System Product** (VM/XA SP) - Replaces VM/SP, VM/SP HPO and VM/XA SF
  - **Virtual Machine/Enterprise Systems Architecture** (VM/ESA), supports S/370, ESA/370 and [ESA/390](/wiki/ESA/390 "ESA/390") (a Unix environment was available starting with[[14]](#cite_note-14) Version 2.)

- - [z/VM](/wiki/Z/VM "Z/VM") (z/Architecture version of the VM OS with 64-bit addressing). Starting with Version 3,[[15]](#cite_note-15) the Unix environment was standard.
