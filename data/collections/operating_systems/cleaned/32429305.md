Not to be confused with [Web desktop](/wiki/Web_desktop "Web desktop").

An **Internet operating system**, or **Internet OS**, is any type of [operating system](/wiki/Operating_system "Operating system") designed to run all of its applications and services through an [Internet](/wiki/Internet "Internet") client,[*[citation needed](/wiki/Wikipedia:Citation_needed "Wikipedia:Citation needed")*] generally a [web browser](/wiki/Web_browser "Web browser"). The advantages of such an OS would be that it would run on a *[thin client](/wiki/Thin_client "Thin client")*, allowing cheaper, more easily manageable computer systems; it would require all applications to be designed on [cross-platform](/wiki/Cross-platform "Cross-platform"), [open standards](/wiki/Open_standards "Open standards"); and would not tie a user's applications, documents, and preferences to a single computer, but rather place them in the [Internet cloud](/wiki/Cloud_computing "Cloud computing"). The Internet OS has also been promoted as the perfect type of platform for [software as a service](/wiki/Software_as_a_service "Software as a service").

## History

Talk of an Internet OS began to surface in 1995 as the [browser war](/wiki/Browser_wars "Browser wars") started heating up between [Microsoft](/wiki/Microsoft "Microsoft") and [Netscape](/wiki/Netscape "Netscape").

In response to the limited capabilities of [HTML](/wiki/HTML "HTML") at the time, Microsoft began developing an online content authoring platform that would be based on distributed [OLE](/wiki/Object_Linking_and_Embedding "Object Linking and Embedding") (Object Linking and Embedding) which it codenamed [Blackbird](/wiki/Blackbird_(online_platform) "Blackbird (online platform)"). Using OLE, applications put on the web would contain their own processing logic, so would act similar to applications in a typical [desktop environment](/wiki/Desktop_environment "Desktop environment").[[1]](#cite_note-1) Immediately, there were concerns that this would tie the web to [proprietary](/wiki/Proprietary_software "Proprietary software") Microsoft technology that wouldn't be guaranteed to run across different systems.[[2]](#cite_note-2)

As a challenge, [Marc Andreessen](/wiki/Marc_Andreessen "Marc Andreessen") of Netscape announced a set of new products that would help transform their browser into what he called an "Internet OS" that would provide the tools and programming interfaces for a new generation of Internet-based applications. The so-called "Internet OS" would still run on top of a regular OS – being based around Netscape Navigator – but he dismissed desktop operating systems like Windows as simply "bag[s] of drivers",[[3]](#cite_note-3) reiterating that the goal would be to "turn Windows into a mundane collection of not entirely debugged device drivers".[[4]](#cite_note-4)

Andreessen explained that the newest versions of Navigator were not just web browsers, but suites of Internet applications, including programs for mail, FTP, news, and more, and would come with viewers for a variety of document types, like [Adobe Acrobat](/wiki/Adobe_Acrobat "Adobe Acrobat"), [Apple QuickTime](/wiki/Apple_QuickTime "Apple QuickTime"), and [Sun Java](/wiki/Sun_Java "Sun Java") applets, which would give it programming interfaces and publishing tools for developers. Netscape also would continue to sell its server software, and [Java applets](/wiki/Java_applets "Java applets") would run cross-platform on both its clients and its servers, and as a scripting language in the form of [JavaScript](/wiki/JavaScript "JavaScript"). They would also provide facilities for backend transaction processing, elaborating the client/server model with navigating clients and application servers and database servers.[[5]](#cite_note-5) He pointed out – because of the broad capabilities that all of this gave their browser – the only difference technically between Netscape Navigator and a traditional operating system is that Navigator didn't include device drivers.[[6]](#cite_note-6)

Technical problems with Blackbird, the growth of the web, and what they saw as competitive statements from Netscape, soon led Microsoft to rethink their strategy and they began to position OLE as a primary tool within Netscape's proposed ecosystem.[[7]](#cite_note-7) OLE would now be embeddable in web pages using an [ActiveX](/wiki/ActiveX "ActiveX") plug-in, and would be easily integrated on the server side using [ASP](/wiki/Active_Server_Pages "Active Server Pages") (Active Server Pages) development.

### The "Gang of Five" and the NC

Main article: [Network Computer](/wiki/Network_Computer "Network Computer")

Opposition in the industry to Microsoft began to grow, as did the concept of an "Internet OS", and this led to the formation of an alliance around developing Java as an alternative to Windows – the chief partners being Netscape, [Sun](/wiki/Sun_Microsystems "Sun Microsystems"), [Oracle](/wiki/Oracle_Corporation "Oracle Corporation"), and [IBM](/wiki/IBM "IBM"). These companies were informally referred to in the industry press as the "Gang of Four". [Novell](/wiki/Novell "Novell") later joined the alliance, leading it to be called the "Gang of Five".[[8]](#cite_note-8)

In May 1997, the group published a position paper which discussed integration of software component models within [CORBA](/wiki/CORBA "CORBA") – a commonly used architecture allowing computer applications from different vendors running on different systems to work together over networks. From this, they then issued several RFPs (Request for Proposals) to the [Object Management Group](/wiki/Object_Management_Group "Object Management Group") (OMG), the standards body responsible for managing CORBA, meant to help integrate different aspects of Java. The proposals included support for [JavaBeans](/wiki/JavaBeans "JavaBeans") – the serialized, component architecture of Java – and for [JavaScript](/wiki/JavaScript "JavaScript").[[9]](#cite_note-9) In what was called the "Java-tization of CORBA", the group was positioning Java to be a distributed object architecture, similar to what Microsoft had intended with OLE in Blackbird. OLE would only exist as a second-class technology that would interface through CORBA using JavaBeans.[[10]](#cite_note-10)

The group also promoted the idea of a [JavaOS](/wiki/JavaOS "JavaOS") – a minimal, Java-based operating system – which would in turn run Netscape's web browser, and through the browser run JavaBeans components. This would be the front for a new ecosystem based on open standards; first, [HTML](/wiki/HTML "HTML") in the web browser; and second, [Java](/wiki/Java_(programming_language) "Java (programming language)"), which they hoped would become widely adopted through CORBA. JavaOS would be hosted on a Network Computer (or NC), a concept long advocated by Oracle. The NC would be a [thin client](/wiki/Thin_client "Thin client") designed only for Internet use, leaving it to access applications and documents stored entirely online. Oracle saw its role as providing tools for the server layer, where network-hosted applications would be provided through the Network Application Server, which in turn would make use of both Oracle7 relationship database management system and the Oracle Web Server. Oracle also outlined what was referred to as the [Network Computing Architecture](/w/index.php?title=Network_Computing_Architecture_(Oracle)&action=edit&redlink=1 "Network Computing Architecture (Oracle) (page does not exist)") (NCA), which would separate presentation, application and data access logic into Java applets or NCA cartridges.[[11]](#cite_note-11)

Microsoft and Intel in response to this challenge put forward a standard for a competing model called the [NetPC](/wiki/NetPC "NetPC"), a diskless PC that would be primarily adapted to web browser use and would run a simplified version of [Windows 95](/wiki/Windows_95 "Windows 95"), codenamed Pegasus. Later down the road, this idea evolved into the [Netbook](/wiki/Netbook "Netbook"). Microsoft publicly criticized the idea of an Internet OS, and instead argued that the traditional desktop OS should be Internet-enabled, the beginning of the idea for [Active Platform](/wiki/Active_Platform "Active Platform"), an Internet strategy that culminated later in the release of [Windows 98](/wiki/Windows_98 "Windows 98"). This strategy, which involved tightly bundling [Internet Explorer](/wiki/Internet_Explorer "Internet Explorer") in Windows, became the center of a United States [antitrust suit](/wiki/United_States_v._Microsoft "United States v. Microsoft") against Microsoft. All of the Gang of Five – Netscape, Sun, IBM, Oracle, and Novell – were involved in lobbying for antitrust action against Microsoft.[[12]](#cite_note-12)

By 1998, the Java alliance started to fall apart. Oracle continued developing server-side Java databases but had given up the idea of the network computer and Netscape had given up on their Java browser efforts, instead aiming to position themselves as an Internet portal. Pressure from investors was given the blame.[[13]](#cite_note-13)

### ChromeOS and ChromiumOS

Main articles: [ChromeOS](/wiki/ChromeOS "ChromeOS") and [ChromiumOS](/wiki/ChromiumOS "ChromiumOS")

[Google](/wiki/Google "Google") revived the idea of the Internet OS in 2009 with the development of [ChromeOS](/wiki/ChromeOS "ChromeOS"), a [Linux](/wiki/Linux "Linux")-based operating system designed to work exclusively with [AJAX](/wiki/AJAX "AJAX")-based web applications. The operating system was designed to look and operate like the [Chrome web browser](/wiki/Google_Chrome "Google Chrome") and be sold on laptops developed with partners, called [Chromebooks](/wiki/Chromebook "Chromebook"). They also promoted [G Suite](/wiki/G_Suite "G Suite"), their suite of web applications, as an alternative to traditional desktop software such as [Microsoft Office](/wiki/Microsoft_Office "Microsoft Office").

Google has tried to address standard criticisms of the Internet OS concept with its development projects. [Google Native Client](/wiki/Google_Native_Client "Google Native Client") allows a browser to run [Intel x86](/wiki/Intel_x86 "Intel x86") native code in a [sandbox](/wiki/Sandbox_(computer_security) "Sandbox (computer security)"), so that more complex programs could run that more fully take advantage of a system's hardware. [Google Gears](/wiki/Google_Gears "Google Gears") was also created to allow offline access of online applications, although this is being deprecated in favour of [web storage](/wiki/Web_storage "Web storage"), a model in the process of standardization by the [World Wide Web Consortium](/wiki/World_Wide_Web_Consortium "World Wide Web Consortium") (W3C).

ChromiumOS is the development version of ChromeOS, but before ChromeOS was available, ChromiumOS's principal user interface was the [Chromium](/wiki/Chromium_(web_browser) "Chromium (web browser)") web browser, which is fully free and open-source, rather than the commercial Google Chrome web browser. As such ChromiumOS does not ship with any of Google's branding and proprietary cloud services preinstalled.
