**Action model learning** (sometimes abbreviated **action learning**) is an area of [machine learning](/wiki/Machine_learning "Machine learning") concerned with the creation and modification of a [software agent](/wiki/Software_agent "Software agent")'s knowledge about the *effects* and *preconditions* of the *actions* that can be executed within its *environment*. This knowledge is usually represented in a logic-based [action description language](/wiki/Action_description_language "Action description language") and used as input for [automated planners](/wiki/Automated_planning "Automated planning").

Learning action models is important when goals change. When an agent acted for a while, it can use its accumulated knowledge about actions in the domain to make better decisions. Thus, learning action models differs from [reinforcement learning](/wiki/Reinforcement_learning "Reinforcement learning"). It enables reasoning about actions instead of expensive trials in the world.[[1]](#cite_note-amir2008-1) Action model learning is a form of [inductive reasoning](/wiki/Inductive_reasoning "Inductive reasoning"), where new knowledge is generated based on the agent's *observations*.

The usual motivation for action model learning is the fact that manual specification of action models for planners is often a difficult, time-consuming, and error-prone task (especially in complex environments).

## Action learning methods

### State of the art

Recent action learning methods take various approaches and employ a wide variety of tools from different areas of [artificial intelligence](/wiki/Artificial_intelligence "Artificial intelligence") and [computational logic](/wiki/Computational_logic "Computational logic"). As an example of a method based on propositional logic, we can mention SLAF (Simultaneous Learning and Filtering) algorithm,[[1]](#cite_note-amir2008-1) which uses agent's observations to construct a long propositional formula over time and subsequently interprets it using a [satisfiability (SAT) solver](/wiki/SAT_solver "SAT solver"). Another technique, in which learning is converted into a satisfiability problem (weighted [MAX-SAT](/wiki/MAX-SAT "MAX-SAT") in this case) and SAT solvers are used, is implemented in ARMS (Action-Relation Modeling System).[[3]](#cite_note-yang2007-3)
Two mutually similar, fully declarative approaches to action learning were based on logic programming paradigm [Answer Set Programming](/wiki/Answer_Set_Programming "Answer Set Programming") (ASP)[[4]](#cite_note-4) and its extension, Reactive ASP.[[5]](#cite_note-5) In another example, bottom-up [inductive logic programming](/wiki/Inductive_logic_programming "Inductive logic programming") approach was employed.[[6]](#cite_note-6) Several different solutions are not directly logic-based. For example, the action model learning using a [perceptron algorithm](/wiki/Perceptron_algorithm "Perceptron algorithm")[[7]](#cite_note-7) or the multi level [greedy search](/wiki/Greedy_search "Greedy search") over the space of
possible action models.[[8]](#cite_note-8) In the older paper from 1992,[[9]](#cite_note-9) the action model learning was studied as an extension of [reinforcement learning](/wiki/Reinforcement_learning "Reinforcement learning").

Nonetheless, further algorithms can be found that operate under different assumptions: FAMA[[10]](#cite_note-10) can work even when some observations are missing, and it produces a general (lifted) planning model. It treats learning an action model like a planning problem, making sure the learned model matches the observations given.
NOLAM[[11]](#cite_note-11) can learn general action models even from noisy or imperfect data.
LOCM[[12]](#cite_note-12) focuses only on the order of actions in the data, ignoring any details about the states between those actions.
The family of safe action model (SAM) learning methods[[13]](#cite_note-13) create models that guarantee any plans made with them will actually work in the real world. There's also an extension called N-SAM[[14]](#cite_note-14) that can learn action models with numeric conditions and effects.

Additionally, numeric action models like N-SAM can be used to improve reinforcement learning (RL) performance through the RAMP algorithm.[[15]](#cite_note-15)

### Literature

Most action learning research papers are published in journals and conferences focused on [artificial intelligence](/wiki/Artificial_intelligence "Artificial intelligence") in general (e.g. Journal of Artificial Intelligence Research (JAIR), Artificial Intelligence, Applied Artificial Intelligence (AAI) or AAAI conferences). Despite mutual relevance of the topics, action model learning is usually not addressed in [planning](/wiki/Automated_planning_and_scheduling "Automated planning and scheduling") conferences like the [International Conference on Automated Planning and Scheduling](/wiki/International_Conference_on_Automated_Planning_and_Scheduling "International Conference on Automated Planning and Scheduling") (ICAPS).
