Inference rules in database theory

**Armstrong's axioms** are a set of [axioms](/wiki/Axiom "Axiom") (or, more precisely, [inference rules](/wiki/Inference_rule "Inference rule")) used to infer all the [functional dependencies](/wiki/Functional_dependency "Functional dependency") on a [relational database](/wiki/Relational_database "Relational database"). They were developed by [William W. Armstrong](/wiki/William_Ward_Armstrong "William Ward Armstrong") in his 1974 paper.[[1]](#cite_note-1) The axioms are [sound](/wiki/Soundness "Soundness") in generating only functional dependencies in the [closure](/wiki/Closure_(mathematics) "Closure (mathematics)") of a set of functional dependencies (denoted as

F

{\displaystyle F^{+}}
![{\displaystyle F^{+}}](https://wikimedia.org/api/rest_v1/media/math/render/svg/d6f68fc8927704e56f96b49d2eade3ce4586506c)) when applied to that set (denoted as

F
{\displaystyle F}
![{\displaystyle F}](https://wikimedia.org/api/rest_v1/media/math/render/svg/545fd099af8541605f7ee55f08225526be88ce57)). They are also [complete](/wiki/Completeness_(logic) "Completeness (logic)") in that repeated application of these rules will generate all functional dependencies in the closure

## Armstrong relation

Given a set of functional dependencies

F
{\displaystyle F}
![{\displaystyle F}](https://wikimedia.org/api/rest_v1/media/math/render/svg/545fd099af8541605f7ee55f08225526be88ce57), an **Armstrong relation** is a relation which satisfies all the functional dependencies in the closure

F

+
{\displaystyle F^{+}}
![{\displaystyle F^{+}}](https://wikimedia.org/api/rest_v1/media/math/render/svg/d6f68fc8927704e56f96b49d2eade3ce4586506c) and only those dependencies. The minimum-size Armstrong relation for a given set of dependencies can have a size which is an exponential function of the number of attributes in the dependencies considered.[[2]](#cite_note-2)
