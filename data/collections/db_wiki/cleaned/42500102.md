This article is a list of [column-oriented database management system](/wiki/Column-oriented_DBMS "Column-oriented DBMS") software.

## Free and open-source software ([FOSS](/wiki/FOSS "FOSS"))

| Database name | Language implemented in | Notes |
| --- | --- | --- |
| Apache Doris | Java & C++ | Open source (since 2017), database for high-concurrency point queries and high-throughput analysis. |
| [Apache Druid](/wiki/Apache_Druid "Apache Druid") | Java | Started in 2011 for low-latency massive ingestion and queries. Support and extensions available from [Imply Data](/wiki/Imply_Data "Imply Data"). |
| [Apache Kudu](/wiki/Apache_Kudu "Apache Kudu") | C++ | Released in 2016 to complete the [Apache Hadoop](/wiki/Apache_Hadoop "Apache Hadoop") ecosystem |
| [Apache Pinot](/wiki/Apache_Pinot "Apache Pinot") | Java | Open sourced in 2015 for real-time low-latency analytics. Support and extensions available from StarTree. |
| [Arc](https://github.com/Basekick-Labs/arc) | Go | Columnar analytical database built on DuckDB, Parquet, and Apache Arrow. Supports Line Protocol, MessagePack, and SQL. Released under AGPL-3.0. Published in 2025 by Basekick Labs for product analytics, observability, IoT telemetry, and AI-agent memory workloads. |
| [Calpont InfiniDB](/wiki/Calpont "Calpont") | C++ |  |
| [ClickHouse](/wiki/ClickHouse "ClickHouse") | C++ | Released in 2016 to analyze data that is updated in real time |
| [CrateDB](/wiki/CrateDB "CrateDB") | Java |  |
| [C-Store](/wiki/C-Store "C-Store") | C++ | The last release of the original code was in 2006; [Vertica](/wiki/Vertica "Vertica") a commercial fork, lives on. |
| [DuckDB](/wiki/DuckDB "DuckDB") | C++ | An embeddable, in-process, column-oriented SQL OLAP RDBMS |
| Databend | Rust | An elastic and reliable Serverless Data Warehouse |
| [InfluxDB](/wiki/InfluxDB "InfluxDB") | Rust | [Time series database](/wiki/Time_series_database "Time series database") |
| [Greenplum](/wiki/Pivotal_Greenplum_Database "Pivotal Greenplum Database") Database | C | Support and extensions available from [VMware](/wiki/VMware "VMware"). |
| [HEAVY.AI](/wiki/HEAVY.AI "HEAVY.AI") | C++ | Formerly [MapD](/wiki/MapD "MapD") |
| [MariaDB](/wiki/MariaDB "MariaDB") ColumnStore | C & C++ | Formerly [Calpont InfiniDB](/wiki/Calpont "Calpont") |
| [Metakit](/wiki/Metakit "Metakit") | C++ |  |
| [MonetDB](/wiki/MonetDB "MonetDB") | C | Open-source (since 2004) columnar Relational DBMS pioneer |
| [PostgreSQL](/wiki/PostgreSQL "PostgreSQL") cstore fdw,[[1]](#cite_note-1) vops[[2]](#cite_note-2) | C | cstore_fdw uses [ORC](/wiki/Apache_ORC "Apache ORC") format |
| StarRocks | Java & C++ | Open source, unified analytics platform for batch and real-time analytics. Supports and extensions available from CelerData. |
| VictoriaMetrics | Go | [Time series database](/wiki/Time_series_database "Time series database")[[3]](#cite_note-3) |
