**Azure Data Explorer** is a fully-managed[[1]](#cite_note-1) [big data](/wiki/Big_data "Big data") analytics [cloud](/wiki/Cloud_computing "Cloud computing") platform[[2]](#cite_note-2)[[3]](#cite_note-3) and [data-exploration](/wiki/Data_exploration "Data exploration") service,[[4]](#cite_note-4) developed by [Microsoft](/wiki/Microsoft "Microsoft"),[[5]](#cite_note-5)[[6]](#cite_note-auto2-6) that ingests [structured](/wiki/Structured_data "Structured data"), [semi-structured](/wiki/Semi-structured_data "Semi-structured data") (like [JSON](/wiki/JSON "JSON")) and [unstructured data](/wiki/Unstructured_data "Unstructured data") (like free-text).[[7]](#cite_note-:1-7)[[8]](#cite_note-auto-8)[[9]](#cite_note-auto1-9)[[10]](#cite_note-10) The service then stores this data and answers analytic ad hoc queries on it with seconds of latency. It is a [full-text indexing](/wiki/Full-text_search "Full-text search") and retrieval database, including [time series](/wiki/Time_series "Time series") analysis capabilities[[6]](#cite_note-auto2-6)[[7]](#cite_note-:1-7) and [regular expression](/wiki/Regular_expression "Regular expression") evaluation and text parsing.[[11]](#cite_note-11)

It is offered as [platform as a service](/wiki/Platform_as_a_service "Platform as a service") (PaaS) as part of [Microsoft Azure](/wiki/Microsoft_Azure "Microsoft Azure") platform. The product was announced by Microsoft in 2018.

## History

The development of the product began in 2014 as a grassroots incubation project in the [Israeli](/wiki/Israel "Israel") [R&D](/wiki/Research_and_development "Research and development") center of Microsoft,[[12]](#cite_note-12) with the internal code name 'Kusto'[[9]](#cite_note-auto1-9)[[7]](#cite_note-:1-7) (named after [Jacques Cousteau](/wiki/Jacques_Cousteau "Jacques Cousteau"), as a reference to "exploring the ocean of data"). The project aim was to address Azure services' needs for fast and scalable log and telemetry analytics.

In 2016 it became the backend big-data and analytics service for Application Insights Analytics.[[13]](#cite_note-13)

The product was announced as a Public Preview product at the [Microsoft Ignite](/wiki/Microsoft_Ignite "Microsoft Ignite") 2018 conference,[[14]](#cite_note-auto3-14) and was announced as a generally available at the Microsoft Ignite conference of February 2019.[[15]](#cite_note-15)

In March 2021, "Kusto EngineV3", Azure Data Explorer's next generation storage and query engine, became generally available. It was designed to provide unparalleled performance for ingesting and querying telemetry, logs, and time series data.[[16]](#cite_note-16)

## Features

Azure Data Explorer offers an optimized [query language](/wiki/Query_language "Query language") and visualizing options[[17]](#cite_note-17) of its data with a [SQL](/wiki/SQL "SQL")-like language called [KQL](/w/index.php?title=Kusto_Query_Language&action=edit&redlink=1 "Kusto Query Language (page does not exist)") (Kusto Query Language[[18]](#cite_note-:2-18)[[19]](#cite_note-19)[[20]](#cite_note-20)).[[7]](#cite_note-:1-7)[[8]](#cite_note-auto-8)

Azure Data Explorer can ingest 200 MB per second per node.[[14]](#cite_note-auto3-14) Data Ingestion methods are pipelines and connectors to common services like Azure Event Grid or Azure Event Hub,[[21]](#cite_note-gartner.com-21) or programmatic ingestion using [SDKs](/wiki/Software_development_kit "Software development kit").

Data visualization can be achieved using their [native dashboard offering](https://dataexplorer.azure.com/dashboards), or with tools like [Power BI](/wiki/Power_BI "Power BI")[[21]](#cite_note-gartner.com-21)[[22]](#cite_note-22) or [Grafana](/wiki/Grafana "Grafana").[[23]](#cite_note-23)[[24]](#cite_note-24)

## Design

Azure Data Explorer is a [distributed database](/wiki/Distributed_database "Distributed database") running on a cluster of compute nodes in [Microsoft Azure](/wiki/Microsoft_Azure "Microsoft Azure"). It is based on [relational database management systems (RDBMS)](/wiki/Relational_Database_Management_Systems "Relational Database Management Systems"), supporting entities such as databases, [tables](/wiki/Table_(database) "Table (database)"), functions, and columns. It supports complex analytics query operators, such as calculated columns, searching and filtering on rows, group by-aggregates and [joins](/wiki/Join_(database) "Join (database)").[[25]](#cite_note-25)

The engine service exposes a [relational data model](/wiki/Relational_model "Relational model"): At the top level ([cluster](/wiki/Database_cluster "Database cluster")) there is a collection of databases, each database contains a collection of tables and stored functions. Each table defines a [schema](/wiki/Database_schema "Database schema") (ordered list of typed fields).

In Azure Data Explorer, unlike a typical [relational database management systems (RDBMS)](/wiki/Relational_Database_Management_Systems "Relational Database Management Systems"), there are no constraints like key uniqueness, [primary](/wiki/Primary_key "Primary key") and [foreign key](/wiki/Foreign_key "Foreign key").[[26]](#cite_note-26) The necessary relationships are established at query time.[[27]](#cite_note-27) The data in Azure Data Explorer generally follows this pattern:[[28]](#cite_note-28) Creating Database, Ingesting data, Query the database.
