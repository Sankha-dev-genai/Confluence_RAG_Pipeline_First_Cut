**BioMart** is a community-driven project to provide a single point of access to distributed [research data](/wiki/Research_data "Research data"). The BioMart project contributes [open source software](/wiki/Open_source_software "Open source software") and data services to the international [scientific community](/wiki/Scientific_community "Scientific community"). Although the BioMart software is primarily used by the [biomedical research](/wiki/Biomedical_research "Biomedical research") community, it is designed in such a way that any type of data can be incorporated into the BioMart framework. The BioMart project originated at the [European Bioinformatics Institute](/wiki/European_Bioinformatics_Institute "European Bioinformatics Institute") as a data management solution[[1]](#cite_note-pmid14707178-1) for the [Human Genome Project](/wiki/Human_Genome_Project "Human Genome Project").[[2]](#cite_note-pmid11237011-2) Since then, BioMart has grown to become a multi-institute collaboration involving various database projects on five continents.[[3]](#cite_note-pmid19144180-3)[[4]](#cite_note-pmid22083790-4)[[5]](#cite_note-pmid19420058-5)[[6]](#cite_note-pmid21930507-6)

## Integration with Ensembl

BioMart is a powerful tool for researchers and bioinformaticians that allows a user to export data from Ensembl, this could include data such as gene ID's, gene positions, associated variations, protein domains and sequences. BioMArt allows the data to be exported into convenient file types like FASTA, XLS, CSV, TSV, HTML. Researchers can use the exported data in a variety of applications, including genomic studies, gene expression analysis, and comparative genomics. BioMart's intuitive interface enables users to customize queries to access specific data sets or features of interest easily[[7]](#cite_note-7)

## Software

BioMart is a freely available, [open-source](/wiki/Open-source_software "Open-source software"), [federated database system](/wiki/Federated_database_system "Federated database system") that provides unified access to disparate, geographically distributed data sources.[[8]](#cite_note-pmid21930506-8) BioMart allows databases hosted on different [servers](/wiki/Server_(computing) "Server (computing)") to be presented seamlessly to users, facilitating collaborative projects. BioMart contains several levels of [query optimization](/wiki/Query_optimization "Query optimization") to efficiently manage large data sets, and offers a diverse selection of [graphical user interfaces](/wiki/Graphical_user_interface "Graphical user interface") and [application programming interfaces](/wiki/Application_programming_interface "Application programming interface") to allow queries to be performed in whatever manner is most convenient for the user. BioMart's capabilities are extended by integration with several widely used software packages such as [Bioconductor](/wiki/Bioconductor "Bioconductor"),[[9]](#cite_note-pmid16082012-9) [Galaxy](/wiki/Galaxy_(computational_biology) "Galaxy (computational biology)"),[[10]](#cite_note-pmid24462600-10) [Cytoscape](/wiki/Cytoscape "Cytoscape"),[[11]](#cite_note-pmid20656902-11) and [Taverna](/wiki/Apache_Taverna "Apache Taverna").[[12]](#cite_note-pmid23640334-12)

## Data sources and community

There are around 40 BioMart data sources including the [Atlas of UTR Regulatory Activity](/wiki/Atlas_of_UTR_Regulatory_Activity "Atlas of UTR Regulatory Activity") (AURA), the [COSMIC cancer database](/wiki/COSMIC_cancer_database "COSMIC cancer database"), [Ensembl](/wiki/Ensembl "Ensembl") Genomes, [HapMap](/wiki/International_HapMap_Project "International HapMap Project"), [InterPro](/wiki/InterPro "InterPro"), [Mouse Genome Informatics](/wiki/Mouse_Genome_Informatics "Mouse Genome Informatics") (MGI), [Rfam](/wiki/Rfam "Rfam") and [UniProt](/wiki/UniProt "UniProt"). Access is provided by institutions including the [European Bioinformatics Institute](/wiki/European_Bioinformatics_Institute "European Bioinformatics Institute") (EBI) and the [Wellcome Trust Sanger Institute](/wiki/Wellcome_Trust_Sanger_Institute "Wellcome Trust Sanger Institute") in the UK, [Cold Spring Harbor Laboratory](/wiki/Cold_Spring_Harbor_Laboratory "Cold Spring Harbor Laboratory") and the [National Center for Biotechnology Information](/wiki/National_Center_for_Biotechnology_Information "National Center for Biotechnology Information") (NCBI) in the United States and [French National Centre for Scientific Research](/wiki/Centre_national_de_la_recherche_scientifique "Centre national de la recherche scientifique") (CNRS).[[13]](#cite_note-community-13) The BioMart Central Portal was established to provide a convenient single point of access to this growing pool of data sources.[[3]](#cite_note-pmid19144180-3)[[5]](#cite_note-pmid19420058-5)[[6]](#cite_note-pmid21930507-6)
