**Amazon Redshift** is a [data warehouse](/wiki/Data_warehouse "Data warehouse") product which forms part of the larger [cloud-computing](/wiki/Cloud-computing "Cloud-computing") platform [Amazon Web Services](/wiki/Amazon_Web_Services "Amazon Web Services").[[1]](#cite_note-1) It is built on top of technology from the [massive parallel processing](/wiki/Massive_parallel_processing "Massive parallel processing") (MPP) data warehouse company [ParAccel](/wiki/ParAccel "ParAccel") (later acquired by [Actian](/wiki/Actian "Actian")),[[2]](#cite_note-2) to handle large scale [data sets](/wiki/Data_set "Data set") and [database migrations](/wiki/Database#Migration "Database"). Redshift differs from Amazon's other hosted database offering, [Amazon RDS](/wiki/Amazon_RDS "Amazon RDS"), in its ability to handle analytic workloads on [big data](/wiki/Big_data "Big data") data sets stored by a [column-oriented DBMS](/wiki/Column-oriented_DBMS "Column-oriented DBMS") principle. Redshift allows up to 16 [petabytes](/wiki/Petabyte "Petabyte") of data on a cluster.[[3]](#cite_note-3) Redshift uses parallel processing and [compression](/wiki/Data_compression "Data compression") to decrease command [execution time](/wiki/Runtime_(program_lifecycle_phase) "Runtime (program lifecycle phase)").[[4]](#cite_note-4)

Amazon Redshift is based on an older version of [PostgreSQL](/wiki/PostgreSQL "PostgreSQL") [8.0.2](/wiki/PostgreSQL#Release_history "PostgreSQL"), and Redshift has made changes to that version.[[5]](#cite_note-5)[[6]](#cite_note-6) An initial [preview beta](/wiki/Software_release_life_cycle#Stages_of_development "Software release life cycle") was released in November 2012[[7]](#cite_note-7) and a full release was made available on February 15, 2013.

Amazon has listed a number of [business intelligence software](/wiki/Business_intelligence_software "Business intelligence software") proprietors as partners and tested tools in their "APN Partner" program,[[8]](#cite_note-partners-8) including [Actian](/wiki/Actian "Actian"), [Actuate Corporation](/wiki/Actuate_Corporation "Actuate Corporation"), [Alteryx](/wiki/Alteryx "Alteryx"), [Dundas Data Visualization](/wiki/Dundas_Data_Visualization "Dundas Data Visualization"), [IBM Cognos](/wiki/Cognos "Cognos"), [InetSoft](/wiki/InetSoft "InetSoft"), [Infor](/wiki/Infor "Infor"), [Logi Analytics](/wiki/Logi_Analytics "Logi Analytics"), [Looker](/wiki/Looker_(company) "Looker (company)"), [MicroStrategy](/wiki/MicroStrategy "MicroStrategy"), [Pentaho](/wiki/Pentaho "Pentaho"),[[9]](#cite_note-9) [Qlik](/wiki/Qlik "Qlik"), [SiSense](/wiki/SiSense "SiSense"), [Tableau Software](/wiki/Tableau_Software "Tableau Software"), and Yellowfin. Partner companies providing data integration tools include [Informatica](/wiki/Informatica "Informatica") and [SnapLogic](/wiki/SnapLogic "SnapLogic"). System integration and consulting partners include [Accenture](/wiki/Accenture "Accenture"), [Deloitte](/wiki/Deloitte "Deloitte"), [Capgemini](/wiki/Capgemini "Capgemini") and [DXC Technology](/wiki/DXC_Technology "DXC Technology").

The "Red" in Redshift's name alludes to [Oracle](/wiki/Oracle_Corporation "Oracle Corporation"), a competing computer technology company sometimes informally referred to as "Big Red" due to its red corporate color. Hence, customers choosing to move their databases from Oracle to Redshift would be "shifting" from "Red".[[10]](#cite_note-10)
