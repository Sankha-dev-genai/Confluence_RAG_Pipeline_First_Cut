**Fluentd** is a [cross-platform](/wiki/Cross_platform "Cross platform") [open-source](/wiki/Open-source_software "Open-source software") [data collection](/wiki/Data_collection "Data collection") software project originally developed at [Treasure Data](/wiki/Treasure_Data "Treasure Data"). It is written primarily in the [C](/wiki/C_(Programming_Language) "C (Programming Language)") programming language with a thin-[Ruby](/wiki/Ruby_(programming_language) "Ruby (programming language)") wrapper that gives users flexibility.[[2]](#cite_note-2)

## Overview

Fluentd was positioned for "[big data](/wiki/Big_data "Big data")," semi- or un-structured data sets. It analyzes [event logs](/wiki/Logfile#Event_logs "Logfile"), [application](/wiki/Application_software "Application software") logs, and [clickstreams](/wiki/Clickstream "Clickstream").[[3]](#cite_note-3) According to Suonsyrjä and Mikkonen, the "core idea of Fluentd is to be the unifying layer between different types of log inputs and outputs.",[[4]](#cite_note-4) Fluentd is available on [Linux](/wiki/Linux "Linux"), [macOS](/wiki/MacOS "MacOS"), and [Windows](/wiki/Microsoft_Windows "Microsoft Windows").[[5]](#cite_note-5)

Fluentd was created by Sadayuki Furuhashi as a project of the [Mountain View](/wiki/Mountain_View,_California "Mountain View, California")-based firm Treasure Data. Written primarily in [Ruby](/wiki/Ruby_(programming_language) "Ruby (programming language)"), its source code was released as [open-source software](/wiki/Open-source_software "Open-source software") in October 2011.[[6]](#cite_note-6)[[7]](#cite_note-fluentd-architecture-7) The company announced $5 million of funding in 2013.[[8]](#cite_note-8)
Treasure Data was then sold to [Arm Ltd.](/wiki/Arm_Ltd. "Arm Ltd.") in 2018.[[9]](#cite_note-9)

## Users

Fluentd was one of the data collection tools recommended by [Amazon Web Services](/wiki/Amazon_Web_Services "Amazon Web Services") in 2013, when it was said to be similar to [Apache Flume](/wiki/Apache_Flume "Apache Flume") or [Scribe](/wiki/Scribe_(log_server) "Scribe (log server)").[[10]](#cite_note-10) [Google Cloud Platform](/wiki/Google_Cloud_Platform "Google Cloud Platform")'s [BigQuery](/wiki/BigQuery "BigQuery") recommends Fluentd as the default real-time data-ingestion tool, and uses Google's customized version of Fluentd, called google-fluentd, as a default logging agent.[[11]](#cite_note-11)[[12]](#cite_note-12)

## Fluent Bit

Fluent Bit is a log processor and log forwarder that is being developed as a [CNCF](/wiki/Cloud_Native_Computing_Foundation "Cloud Native Computing Foundation") sub-project under the umbrella of Fluent project.[[13]](#cite_note-13) Fluentd is written in [C](/wiki/C_(programming_language) "C (programming language)") and [Ruby](/wiki/Ruby_(programming_language) "Ruby (programming language)") and consumes at least 60 [megabytes](/wiki/Megabyte "Megabyte") of memory. [Fluent Bit](/wiki/Fluent_Bit "Fluent Bit") is written only in C, with no dependencies, and consumes approximately one megabyte of memory, making it easier to run under [embedded Linux](/wiki/Linux_on_embedded_systems "Linux on embedded systems") and in [containers](/wiki/Containerization_(computing) "Containerization (computing)").[[14]](#cite_note-14)
