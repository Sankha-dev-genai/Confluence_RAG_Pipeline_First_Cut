**DATAllegro** was a company that specialized in [data warehousing](/wiki/Data_warehouse "Data warehouse") appliances. It was founded by Stuart Frost in 2003 inspired by and as a competitor to [Data warehouse appliance](/wiki/Data_warehouse_appliance "Data warehouse appliance") pioneer [Netezza](/wiki/Netezza "Netezza").[[1]](#cite_note-1) DATAllegro - like Netezza - used open source software stack ([Ingres](/wiki/INGRES "INGRES") DBMS running on [Linux](/wiki/Linux "Linux")). [Microsoft](/wiki/Microsoft "Microsoft") announced it had acquired DATAllegro as of September 2008.[[2]](#cite_note-2) SQL Server Parallel Data Warehouse (PDW) is the successor product to DATAllegro on Windows Server using a version of the SQL Server database engine.[[3]](#cite_note-3)
