## Authentication

All requests use a bearer token in the `Authorization` header.

```
curl -H "Authorization: Bearer $TOKEN" \
     https://api.example.com/v1/items
```

## Endpoints

| Method | Path | Description |
| --- | --- | --- |
| GET | /v1/items | List items |
| POST | /v1/items | Create an item |
| GET | /v1/items/{id} | Fetch one item |
| DELETE | /v1/items/{id} | Delete an item |

## Example response

```
{
  "id": 42,
  "name": "Widget",
  "status": "active"
}
```

Rate limit: 100 requests/minute per token.
