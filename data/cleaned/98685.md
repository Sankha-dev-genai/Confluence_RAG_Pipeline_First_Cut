## Deploy procedure

1. Announce in #deploys
2. Tag the release
3. Run the pipeline
4. Verify health checks
5. Announce completion

```
git tag v1.0.0
git push origin v1.0.0
# CI/CD takes over from here
```

## Rollback

If health checks fail, roll back immediately.

```
kubectl rollout undo deployment/api
```
